# Hands-on 09 : The UN Resolution World Map for Equality : Mercator vs Equal Earth Projection

**Duration:** 1–2 hours
**Level:** Master students

## Objective

Compare how **Mercator** and **Equal Earth** projections represent the world and how projection choice affects interpretation.

## Activities

### 1. Create Two World Maps

Create and compare:

* Mercator Projection
* Equal Earth Projection

### 2. Compare Distortion

Observe:

* Greenland
* Africa
* Russia
* South America

Key characteristics:

* **Mercator:** Preserves local angles and shapes, but strongly enlarges areas at high latitudes.
* **Equal Earth:** Preserves area, but does not preserve local shape.

### 3. Quantify Area Effect

Select 5–6 countries and compare:

* True geodesic area
* Area measured in Mercator
* Area measured in Equal Earth

### 4. Discussion

> **How can map projection change the message of a thematic map?**

## Expected Conclusion

* **Mercator →** navigation and conformal mapping
* **Equal Earth →** global thematic mapping and area comparison
