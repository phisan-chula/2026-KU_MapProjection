Hands-on: Mercator vs Equal Earth Projection

Duration: 1–2 hours | Level: Master students

Objective: Compare how Mercator and Equal Earth represent the world and how projection choice affects interpretation.

Create two world maps
Mercator
Equal Earth
Compare distortion
Observe Greenland, Africa, Russia, South America.
Mercator: preserves local angles/shapes, strongly enlarges high latitudes.
Equal Earth: preserves area, but not local shape.
Quantify area effect
Select 5–6 countries and compare projected area with true geodesic area.
Application
Map one global dataset, e.g. population, CO₂, forest cover, or disaster risk, using both projections.
Discussion
Question: How can map projection change the message of a thematic map?

Expected conclusion:
Mercator → navigation / conformal mapping
Equal Earth → global thematic mapping / area comparison
