แบบฝึกหัดที่ 7: Map Graticule, Distortion and Tissot Indicatrix for Conic Projection
รายวิชา: การฉายแผนที่ (Map Projection)  
กำหนดส่ง: วันศุกร์ที่ 28 สิงหาคม 2569 ก่อนเวลา 11:00 น.

1. วัตถุประสงค์
แบบฝึกหัดนี้มีวัตถุประสงค์เพื่อให้นิสิตสามารถ
เข้าใจลักษณะของ Conic Projection และรูปแบบของเส้นกรaticule
อธิบายลักษณะของเส้น Meridian และ Parallel บนแผนที่แบบกรวยได้
วิเคราะห์ความผิดเพี้ยน (Map Distortion) ที่เกิดขึ้นจากการฉายแผนที่
ใช้ Tissot Indicatrix เพื่อแสดงการเปลี่ยนแปลงของ
รูปร่าง (shape)
ขนาด/พื้นที่ (area)
ระยะทาง (distance)
มุม (angle)
เปรียบเทียบความผิดเพี้ยนในบริเวณต่าง ๆ ของแผนที่ Conic Projection
---
2. Projection ที่ใช้
ให้ใช้ Lambert Conformal Conic (LCC) เป็น Conic Projection หลักในการทดลอง
แนวคิดสำคัญของ LCC:
Meridian เป็นเส้นตรงที่ลู่เข้าหากัน
Parallel เป็นส่วนโค้งของวงกลมร่วมศูนย์กลาง
มี Standard Parallel หนึ่งหรือสองเส้น
บริเวณใกล้ Standard Parallel จะมีความผิดเพี้ยนของสเกลต่ำ
เป็นการฉายแบบ Conformal ดังนั้นรูปร่างและมุมในบริเวณเล็ก ๆ จะถูกรักษาไว้
---  
3. งานที่ต้องทำ
3.1 สร้าง Map Graticule
สร้างแผนที่ด้วย Lambert Conformal Conic Projection โดยให้แสดง
เส้นละติจูด (Parallels)
เส้นลองจิจูด (Meridians)
Equator
Central Meridian
Standard Parallel ทั้งสองเส้น
ขอบเขตประเทศหรือทวีปเพื่อใช้เป็นข้อมูลอ้างอิง
ให้สังเกตและอธิบายว่า
Meridian มีรูปร่างอย่างไร
Parallel มีรูปร่างอย่างไร
Meridian และ Parallel ตัดกันด้วยลักษณะใด
ระยะห่างของ Parallel เปลี่ยนแปลงอย่างไรเมื่อห่างจาก Standard Parallel
---
3.2 แสดง Tissot Indicatrix
วาง Tissot Indicatrix เป็นตารางบนพื้นที่ศึกษา โดยควรกระจายให้ครอบคลุมบริเวณ
ใกล้ Standard Parallel
ระหว่าง Standard Parallel
เหนือ Standard Parallel
ใต้ Standard Parallel
ใกล้ขอบแผนที่
ให้ใช้ Indicatrix ที่มีขนาดเริ่มต้นเท่ากันบนผิวโลก แล้วแสดงผลหลังการฉายลงบนแผนที่
---
3.3 วิเคราะห์ Map Distortion
จาก Tissot Indicatrix ให้ตอบคำถามต่อไปนี้
บริเวณใดมีความผิดเพี้ยนน้อยที่สุด
บริเวณใดมีความผิดเพี้ยนมากขึ้น
เมื่อเคลื่อนที่ออกจาก Standard Parallel ขนาดของ Indicatrix เปลี่ยนแปลงอย่างไร
รูปร่างของ Indicatrix ยังคงเป็นวงกลมหรือเปลี่ยนเป็นวงรี เพราะเหตุใด
LCC รักษาคุณสมบัติใดได้ดี
LCC ไม่สามารถรักษาคุณสมบัติใดให้ถูกต้องทั่วทั้งแผนที่
Standard Parallel มีความสำคัญต่อการควบคุม distortion อย่างไร
---
4. การทดลองเพิ่มเติม
ให้เปลี่ยนตำแหน่งของ Standard Parallels อย่างน้อย 2 กรณี แล้วเปรียบเทียบผล เช่น
กรณี A (หน้า 1)
```text
Standard Parallel 1 = 10°N
Standard Parallel 2 = 30°N
```
กรณี B (หน้า 2)
```text
Standard Parallel 1 = 15°N
Standard Parallel 2 = 25°N
```
เปรียบเทียบว่า
พื้นที่ที่มี distortion ต่ำเปลี่ยนตำแหน่งอย่างไร
ขนาดของ Tissot Indicatrix เปลี่ยนแปลงอย่างไร
การเลือก Standard Parallel ที่แตกต่างกันเหมาะสมกับพื้นที่ลักษณะใด
---

---
6. คำถามสรุป
ตอบคำถามต่อไปนี้โดยสรุป
เพราะเหตุใด Conic Projection จึงเหมาะกับพื้นที่ที่มีแนวตะวันออก–ตะวันตกกว้างกว่าทิศเหนือ–ใต้
Standard Parallel คืออะไร
ที่ Standard Parallel ค่า scale factor ควรมีค่าเท่าใด
เพราะเหตุใด distortion จึงเพิ่มขึ้นเมื่ออยู่ห่างจาก Standard Parallel
Tissot Indicatrix สามารถบอก distortion ชนิดใดได้บ้าง
เพราะเหตุใด Tissot Indicatrix ของ Lambert Conformal Conic จึงยังคงมีลักษณะเป็นวงกลมในบริเวณเล็ก ๆ
หากออกแบบ Conic Projection สำหรับประเทศไทย ควรพิจารณาเลือก Standard Parallel จากปัจจัยใดบ้าง
